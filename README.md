# Setup
0. (optional) `brew untap foreai-co/tap`: Untap this repo to force a reload, `brew update` might suffice.
1. `brew tap foreai-co/tap`: Configure this repostiory as a Homebrew tap.
2. `brew install forecli`: Install the `fore` CLI tool. (Or whatever else may be here.)
3. `brew upgrade forecli`: Update the `fore` CLI tool.
